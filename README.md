# 御龙高手

Windows PC 离线单机游戏开发项目。目标是依据可追溯资料复刻含后期内容的手机版《龙之牧场 / 育龙高手》。目前交付 **v0.16.63 奇遇流程修复版**，不是高保真完成版。


任务：左侧“任务”开启原后教程任务链，147条按原顺序同时开放10条，支持前往、详情/奖励切换、真实条件判定和一次发奖。旧档首次进入才开始记指定操作，重启保留；依赖未恢复玩法的差异见 docs/MISSIONS.md。

活动道具：随机礼包批量开启，活动背包/仓库可合成32种龙蛋碎片，使用原数量与结果面板；31种有原中文成本，冰月明确标记离线10片。保留钥匙宝箱限制和未知材料库存。

高级扭蛋的单机调整：远古龙基础概率20%，连续未出远古时第10抽保底，支持三眼魔、高能威、大圣、大黄蜂、火凤凰。原服务器概率未取得，其他历史活动奖池未改权重。旧扭蛋奖励和玩家存档保留。

活动目录按用户要求由76个重复分期入口精简为43项。九类同系列合并，进入后选择具体分期/奖池；各期原奖励、库存和已领取记录保留，搜索具体龙名也能找到系列入口。

装备列表支持滚轮横向滚动，也可按住左键拖动卡片；拖动经过升星/强化按钮不会误点击，普通点击照常可用。

点击左上头像进入原玩家信息页，可修改昵称（最多6字，首次免费，之后100魔晶）和选择已拥有龙的头像；数据自动保存。繁殖加速采用原费用并推进原任务，完工祭坛解锁龙15/20/25/30级上限，原25/30级任务须有两条对应等级龙。旧档等级和资源不重置，任务剩余差异见docs/MISSIONS.md。

农场：购买的普通、大型、超级农场和进化圣地现可独立种植、按原剩余时间公式扣魔晶加速、收获及保存；饲料进入龙粮，进化圣地产出进入可消费的进化果实库存。每座农场独立升级，原基础农场旧作物保留。其他功能建筑接通状态见 docs/BUILDINGS.md。

龙翼：修正可见翼片切到隐藏帧时向零坐标漂移的问题，按原 CCTween 的显示切换规则保持末帧位置；全模型共用此修复。

竞技之神：地图入口打开原版四对手面板，可挑战单机NPC、查看战绩、领取每日排名奖章/魔晶、兑换原配置物资；10魔晶买次数、50魔晶清冷却，VIP购买上限和免冷却生效。NPC排名/战力、每日5次/10分钟冷却、每日领奖时点为明确的离线规则。

VIP：VIP0—10原门槛和部分特权已生效：牧场经验/产金/农场龙粮加成，繁殖/孵化/建造耗时缩减，以及竞技次数购买上限和免冷却。新增任务按操作时VIP计时；旧任务不重算。

活动：活动中心沿用主分支整理后的19个入口，保留76个源配置及旧领取记录；大富翁一个入口内选择原版三岛。已接入领取/兑换、抽奖、培养、龙蛋收集与重启保存；缺服务器数据的玩法明确标识本地规则，不代表全部历史版本完美复刻。详见 [活动范围与缺口](docs/ACTIVITIES.md)。

顶部资源栏：活动、龙巢、扩建和商店页面的金币/魔晶/龙魂加号均可使用；购买或充值后关闭返回原页面，刷新余额并保留滚动位置。

## 运行
- 双击 `启动游戏.cmd`，优先运行已打包 Windows 程序。
- 开发模式：Node.js 22.12+，`npm ci`，`node node_modules/electron/install.js`（首次下载桌面运行时），`npm start`。
- 可选浏览器预览：`npm run dev` → http://127.0.0.1:4173 。浏览器与桌面存档独立。
- `npm test` 检查规则与存档；`npm run package` 生成 `dist/御龙高手-v0.16.63-win32-x64/御龙高手.exe`（整个目录一起保留）。


活动抽奖显示：8格与12格奖池分别排版，缺失品质按物品实际品质显示；开奖只弹奖励和关闭按钮，关闭/×/Esc返回原抽奖页。

抽奖显示：修复Windows减少动态效果开启时奖品一直透明的问题；扭蛋机播完原动作后显示结果，已抽奖品保存在仓库。

游戏动作：牧场播放原骨骼呼吸／行走／才艺；战斗按原客户端使用成年模型、1024×768 战场和未压缩陆空阵位；入场结束才开战，攻击抬手结束后进入收招并按源技能类型播放弹道／闪电、前后景命中特效，死亡动作播完后退场。Windows 的“减少动态效果”不会再将游戏骨骼锁在首帧。

牧场操作：滚轮围绕鼠标缩放；空白处按住左键拖动视角，双击恢复。移动建筑显示黄色/红色占地格，确认后保存；施工建筑可打开加速窗口花魔晶完成。扩建已按原具名配置改为金币/魔晶二选一，点击购买木牌选地；已有岛扩完再解锁下一岛，费用为10万金币、125魔晶、500魔晶。旧档岛屿和已买空间保留；未购地块使用原遮罩；新增／移动建筑按整片占地检查，跨入未购地块会变红并禁止确认。旧建筑位置保留，原全局坐标仍需继续核对。

符文获取：更多 → 符文 → 神符数量旁的＋ → 免费领取/购买；寻访亮起的NPC，拾取掉落，再点“使用符文”在原版三栏页面为蓝色及以上品质的龙镶嵌（支持一键镶嵌）。寻访权重和NPC推进采用已登记的离线解释，未宣称与服务器概率一致。

宝石获取：更多 → 宝石 → 获取宝石，可免费探索或使用龙珠/魔晶。商店 → 资源出售原启用中/高级龙珠（5颗/120或300魔晶）；三档离线池映射与保底算法仍需服务器证据。

装备功能：一键装备按原品质/阶级推荐填充空槽；手动更换会将原装备退回背包。支持单次/十次强化、蓝装三星/紫橙五星、分解与碎片合成，评分和强化预览计入累计星级属性，原穿戴/强化成功特效已接入。随机词条、条件属性和服务器强化结算仍未完全核实。

装备材料：更多 → 装备 → 装备分解，选择闲置装备、确认得到强化石/羽翼/水晶，再切装备强化使用。已穿戴装备须先卸下；取消分解不消耗装备。冒险胜利现按关卡源掉落包获得物品；仓库中的领主宝箱须配对应钥匙，开出的装备可穿戴/分解，碎片在装备页合成。概率采用离线解释。

## 当前玩法
1. 岛上点击农场，选择龙涎草（50 金币，30 秒，10 食物），或其他两种初级作物。农场可按原版等级、价格与时间升级，逐步开放 6 / 9 种作物。
2. 点击牧场里的龙，或“更多 → 我的龙族”，点击已拥有的龙，进入原版布局喂养页；我的龙族可横向滚动，并按全部或九种元素筛选，混合龙会匹配所有自身属性；每级喂养 4 次，Lv4 可以繁殖。Lv4/Lv7 切换成长外观。
3. 繁殖巢选择两只不同龙。可预览客户端基础池；服务端加成尚未核对。本地结果在开始时确定并保存，时长使用对应后代的原版配置，可能是数小时。
4. 繁殖完成领取龙蛋、转入独立育龙塔，再选择栖息地迎接幼龙。孵化中可按原客户端公式花魔晶立即完成；完成后可放入龙巢或按该龙原配置价格出售。扭蛋仓库中的龙蛋也可直接出售。育龙塔孵化时，培育山能开启下一轮。塔被占用时新蛋留在山中，栖息地满时幼龙留在塔中。亲代繁殖期间暂停喂养/迁移并从栖息地移到山旁。
5. 点击“收金币”收全部产出。“更多”访问存档、图鉴和养成。关闭游戏后计时继续。

87条龙的三个成长阶段现使用原版骨骼模型播放，共269个模型、1841段动作（含8种原版觉醒形态）。成长外观随等级切换；动作完整性在隔离对照程序中验证。动作预览不代表战斗系统已实现。水晶/风/镜龙模型和图像仍缺失；76条龙蛋图已关联，其余14条留空。数值缓动、动作衔接、粒子和部分特效仍需与原版逐项比对。

栖息地现接入9种元素、18个原版定义：原版容量/存金上限、价格（含魔晶）、牧场等级门槛、建造/升级计时、完成经验、元素入住限制。17个在商店开放；41号大型传奇龙巢的客户端商店标志为关闭，不擅自开放。牧场里可拖动栖息地保存位置。点击龙巢打开原信息弹窗；更多→商店→龙巢，使用原商品卡建造/升级；喂养→移动选择龙巢。繁殖使用原双列表选亲代，孵化使用原育龙塔/幼龙弹窗。旧通用栖息地保留容量3和原有龙、金币；新建采用元素规则。

尚未还原：原版等距地块/碰撞细节、升级期间产金细节、原版位图字体/部分界面细节、动作缓动/粒子和未收集皮肤、完整掉落限制/升星/随机属性、真实战斗结算、历史活动与服务器抽奖概率。扩建、六槽装备实例、冒险地图/关卡界面、充值测试到账、资源商店及三机离线抽取已接入，但仍须继续逐项对照。繁殖和抽奖的离线池不等于服务器实际概率。

商城六分类现都能进入：龙蛋47项、龙巢17项、建筑18项、装饰33项、扩建阶梯和资源商品均来自当前客户端配置。龙巢、扩建和资源已经可交易；龙蛋/建筑/装饰目前完成原目录、价格、等级、占地与详情展示，购买后生成建筑或龙蛋的玩法还在接入，不能把目录可见称为全部商品已可购买。

进化条件入口现可查看原版页面、15/25级门槛及对应品质的材料需求。当前只读预览，实际突破、果实库存和总战斗属性仍未实现；不能据此称进阶完成。“更多→原版龙谱→获取途径”可逐龙查看商店配置和全部正权重繁殖候选，抽奖/活动/冒险来源仍待核实。

## 存档
桌面正式存档：工程根目录 `player-data/saves/ranch-v1.json`（旧 `%APPDATA%/YulongRanch/saves/ranch-v1.json` 仅作首次迁移来源），上一有效状态为 `.json.bak`。内部格式为v12并兼容迁移v1–v11，旧文件名保留以连续读取原存档。临时文件同步落盘后替换主文件。损坏时尝试备份，两个文件都不可读时阻止载入，避免覆盖。高版本存档阻止回退。

## 项目结构
- `src/game.mjs`：独立规则及存档校验，`src/data.mjs`：已接入原版数据与尚待替换的测试配置。
- `src/app.mjs` / `src/art.mjs` / `src/style.css`：界面；`src/original-hud.mjs`：原版布局 HUD。
- `desktop/`：Electron 安全隔离、本地存档与桌面验收。
- `tests/`：规则边界、离线计时、容量、损坏恢复、顺序写入验证。
- `docs/BASELINE.md`：初始检查；`docs/EVIDENCE.md`：来源；`docs/GAPS.md`：功能差异。
- `DEVELOPMENT.md`：续作记录与优先待办。

后期系统已记录范围，尚未实现的内容在差异清单和游戏“复刻进度”中明确说明。排除真人联机。

三栏网页导航、白色管理卡与网页图鉴已从运行界面移除。商城/龙巢/种植/繁殖/育龙塔/幼龙/图鉴使用对应客户端布局和图片；本地存档、任务引导与来源说明使用原纸板窗口，属于离线适配，不能宣称这些页面原版完全一致。缺失的玩法与精确宽屏/字体/动作继续见docs/GAPS.md。

“更多→仓库”可查看扭蛋、活动与碎片合成的龙蛋，送入育龙塔孵化；道具可选择数量开启或合成。旧两档抽奖待领取结果保留兼容安置入口，满巢仍保留，重启不重复领取。未恢复的旧材料用途见差异清单。

冒险奖励：首杀按源表追加一次奖励；战败不扣体力。特殊资源点先打守卫，再每3小时领取、每天最多3次；日界采用离线UTC+8规则。史诗箱钥匙的普通获取、服务器概率/敌队映射、技能结算与粒子仍未全部还原。

## v0.16.63 奇遇流程

- 奇遇改为培育完成时自动判定，倒计时按秒刷新，过期及时移除，帮助返回保留当前事件；使用原版193×109标签尺寸，避免事件卡重叠。
