# 御龙高手

Windows PC 离线单机游戏开发项目。目标是依据可追溯资料复刻含后期内容的手机版《龙之牧场 / 育龙高手》。目前交付 **v0.16.26 冒险掉落与装备获取版**，不是高保真完成版。

## 运行
- 双击 `启动游戏.cmd`，优先运行已打包 Windows 程序。
- 开发模式：Node.js 22.12+，`npm ci`，`node node_modules/electron/install.js`（首次下载桌面运行时），`npm start`。
- 可选浏览器预览：`npm run dev` → http://127.0.0.1:4173 。浏览器与桌面存档独立。
- `npm test` 检查规则与存档；`npm run package` 生成 `dist/御龙高手-v0.16.26-win32-x64/御龙高手.exe`（整个目录一起保留）。

牧场操作：滚轮围绕鼠标缩放；空白处按住左键拖动视角，双击恢复。移动建筑显示黄色/红色占地格，确认后保存；施工建筑可打开加速窗口花魔晶完成。扩建会增加可摆放区域，但原四岛地块解锁布局尚未完全核实。

符文获取：更多 → 符文 → 神符数量旁的＋ → 免费领取/购买；寻访亮起的NPC，拾取掉落，再点“使用符文”为绿色品质及以上龙装备。寻访权重和NPC推进采用已登记的离线解释，未宣称与服务器概率一致。

宝石获取：更多 → 宝石 → 获取宝石，可免费探索或使用龙珠/魔晶。商店 → 资源出售原启用中/高级龙珠（5颗/120或300魔晶）；三档离线池映射与保底算法仍需服务器证据。

装备材料：更多 → 装备 → 装备分解，选择闲置装备、确认得到强化石/羽翼/水晶，再切装备强化使用。已穿戴装备须先卸下；取消分解不消耗装备。冒险胜利现按关卡源掉落包获得物品；仓库中的领主宝箱须配对应钥匙，开出的装备可穿戴/分解，碎片在装备页合成。概率采用离线解释。

## 当前玩法
1. 岛上点击农场，选择龙涎草（50 金币，30 秒，10 食物），或其他两种初级作物。农场可按原版等级、价格与时间升级，逐步开放 6 / 9 种作物。
2. 点击牧场里的龙，或“更多 → 我的龙族”，点击已拥有的龙，进入原版布局喂养页；我的龙族可横向滚动，并按全部或九种元素筛选，混合龙会匹配所有自身属性；每级喂养 4 次，Lv4 可以繁殖。Lv4/Lv7 切换成长外观。
3. 繁殖巢选择两只不同龙。可预览客户端基础池；服务端加成尚未核对。本地结果在开始时确定并保存，时长使用对应后代的原版配置，可能是数小时。
4. 繁殖完成领取龙蛋、转入独立育龙塔，再选择栖息地迎接幼龙。孵化中可按原客户端公式花魔晶立即完成；完成后可放入龙巢或按该龙原配置价格出售。扭蛋仓库中的龙蛋也可直接出售。育龙塔孵化时，培育山能开启下一轮。塔被占用时新蛋留在山中，栖息地满时幼龙留在塔中。亲代繁殖期间暂停喂养/迁移并从栖息地移到山旁。
5. 点击“收金币”收全部产出。“更多”访问存档、图鉴和养成。关闭游戏后计时继续。

87条龙的三个成长阶段现使用原版骨骼模型播放，共261个模型、1734段动作。成长外观随等级切换；动作完整性在隔离对照程序中验证。动作预览不代表战斗系统已实现。水晶/风/镜龙模型和图像仍缺失；76条龙蛋图已关联，其余14条留空。数值缓动、动作衔接、粒子和部分特效仍需与原版逐项比对。

栖息地现接入9种元素、18个原版定义：原版容量/存金上限、价格（含魔晶）、牧场等级门槛、建造/升级计时、完成经验、元素入住限制。17个在商店开放；41号大型传奇龙巢的客户端商店标志为关闭，不擅自开放。牧场里可拖动栖息地保存位置。点击龙巢打开原信息弹窗；更多→商店→龙巢，使用原商品卡建造/升级；喂养→移动选择龙巢。繁殖使用原双列表选亲代，孵化使用原育龙塔/幼龙弹窗。旧通用栖息地保留容量3和原有龙、金币；新建采用元素规则。

尚未还原：原版等距地块/碰撞细节、升级期间产金细节、原版位图字体/部分界面细节、动作缓动/粒子和未收集皮肤、完整掉落限制/升星/随机属性、真实战斗结算、历史活动与服务器抽奖概率。扩建、六槽装备实例、冒险地图/关卡界面、充值测试到账、资源商店及三机离线抽取已接入，但仍须继续逐项对照。繁殖和抽奖的离线池不等于服务器实际概率。

商城六分类现都能进入：龙蛋47项、龙巢17项、建筑18项、装饰33项、扩建阶梯和资源商品均来自当前客户端配置。龙巢、扩建和资源已经可交易；龙蛋/建筑/装饰目前完成原目录、价格、等级、占地与详情展示，购买后生成建筑或龙蛋的玩法还在接入，不能把目录可见称为全部商品已可购买。

进化条件入口现可查看原版页面、15/25级门槛及对应品质的材料需求。当前只读预览，实际突破、果实库存和总战斗属性仍未实现；不能据此称进阶完成。“更多→原版龙谱→获取途径”可逐龙查看商店配置和全部正权重繁殖候选，抽奖/活动/冒险来源仍待核实。

## 扭蛋机
“更多→基础抽奖”打开后期原版初级／中级／高级三台扭蛋机，使用原布局、原骨骼模型、原开奖动作、原龙蛋结果页和53项奖品预览。中级100/900、高级280/2500来自原客户端；有券时界面按原逻辑显示1/10张券，一张券只抵一次抽取。开奖后显示原“恭喜你获得以下龙蛋”页面，可确定返回或再来一次；结果先保存到仓库，再送育龙塔孵化。初级免费次数/冷却、基因中心及服务器真实池与概率仍未取得；当前奖池和权重明确属于离线推断。

此前v0.10/v0.11的两档占卜是客户端保留的另一套旧系统，不能当作后期扭蛋机。旧离线程序、存档及旧包保留，不混接到新的三档按钮。`抽奖试玩.cmd`仍使用独立演示档；完整抽奖玩法尚未复刻。

## 存档
桌面存档：`%APPDATA%/YulongRanch/saves/ranch-v1.json`，上一有效状态为 `.json.bak`。内部格式已升至v10并兼容迁移v1–v9，旧文件名保留以连续读取原存档。临时文件同步落盘后替换主文件。损坏时尝试备份，两个文件都不可读时阻止载入，避免覆盖。高版本存档阻止回退。

“存档”按钮支持保存与 JSON 导入/导出。导入会验证版本、资源、龙、容量、计时和编号。Ctrl+S 可手动保存。自动保存失败会保留界面中的旧状态并提示重试。

## 项目结构
- `src/game.mjs`：独立规则及存档校验，`src/data.mjs`：已接入原版数据与尚待替换的测试配置。
- `src/app.mjs` / `src/art.mjs` / `src/style.css`：界面；`src/original-hud.mjs`：原版布局 HUD。
- `desktop/`：Electron 安全隔离、本地存档与桌面验收。
- `tests/`：规则边界、离线计时、容量、损坏恢复、顺序写入验证。
- `docs/BASELINE.md`：初始检查；`docs/EVIDENCE.md`：来源；`docs/GAPS.md`：功能差异。
- `DEVELOPMENT.md`：续作记录与优先待办。

后期系统已记录范围，尚未实现的内容在差异清单和游戏“复刻进度”中明确说明。排除真人联机。

三栏网页导航、白色管理卡与网页图鉴已从运行界面移除。商城/龙巢/种植/繁殖/育龙塔/幼龙/图鉴使用对应客户端布局和图片；本地存档、任务引导与来源说明使用原纸板窗口，属于离线适配，不能宣称这些页面原版完全一致。缺失的玩法与精确宽屏/字体/动作继续见docs/GAPS.md。

“更多→仓库”现可查看旧两档抽奖已经保存的待领取结果，筛选龙/道具、领取资源、选择可用龙巢安置旧奖励。满巢仍保留，重启不重复领取。当前仅是旧奖励兼容入口；后期扭蛋入仓/龙蛋使用和完整物品库存尚未接入，不把直接安置旧奖励当成后期仓库规则。

冒险奖励：首杀按源表追加一次奖励；战败不扣体力。特殊资源点先打守卫，再每3小时领取、每天最多3次；日界采用离线UTC+8规则。史诗箱钥匙的普通获取、服务器概率/敌队映射、技能结算与粒子仍未全部还原。
