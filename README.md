# 御龙高手

Windows PC 离线单机游戏开发项目。目标是依据可追溯资料复刻含后期内容的手机版《龙之牧场 / 育龙高手》。目前交付 **v0.11 原版入口调整与基础抽奖版**，不是高保真完成版。

## 运行
- 双击 `启动游戏.cmd`，优先运行已打包 Windows 程序。
- 开发模式：Node.js 22.12+，`npm ci`，`node node_modules/electron/install.js`（首次下载桌面运行时），`npm start`。
- 可选浏览器预览：`npm run dev` → http://127.0.0.1:4173 。浏览器与桌面存档独立。
- `npm test` 检查规则与存档；`npm run package` 生成 `dist/御龙高手-v0.11.0-win32-x64/御龙高手.exe`（整个目录一起保留）。

## 当前玩法
1. 岛上点击农场，选择龙涎草（50 金币，30 秒，10 食物），或其他两种初级作物。农场可按原版等级、价格与时间升级，逐步开放 6 / 9 种作物。
2. 点击牧场里的龙，或“更多 → 我的龙族”，点击已拥有的龙，进入原版布局喂养页；我的龙族可横向滚动，并按全部或九种元素筛选，混合龙会匹配所有自身属性；每级喂养 4 次，Lv4 可以繁殖。Lv4/Lv7 切换成长外观。
3. 繁殖巢选择两只不同龙。可预览客户端基础池；服务端加成尚未核对。本地结果在开始时确定并保存，时长使用对应后代的原版配置，可能是数小时。
4. 繁殖完成领取龙蛋、转入独立育龙塔，再选择栖息地迎接幼龙。育龙塔孵化时，培育山能开启下一轮。塔被占用时新蛋留在山中，栖息地满时幼龙留在塔中。亲代繁殖期间暂停喂养/迁移并从栖息地移到山旁。
5. 点击“收金币”收全部产出。“更多”访问存档、图鉴、养成和进度。关闭游戏后计时继续。

87条龙的三个成长阶段现使用原版骨骼模型播放，共261个模型、1734段动作。可在“我的龙族→查看成长与动作”切换幼年/成长/成年和呼吸、步行、特殊动作、成年战斗动作。动作预览不代表战斗系统已实现。水晶/风/镜龙模型和图像仍缺失；76条龙蛋图已关联，其余14条留空。数值缓动、动作衔接、粒子和部分特效仍需与原版逐项比对。

栖息地现接入9种元素、18个原版定义：原版容量/存金上限、价格（含魔晶）、牧场等级门槛、建造/升级计时、完成经验、元素入住限制。17个在商店开放；41号大型传奇龙巢的客户端商店标志为关闭，不擅自开放。牧场里可拖动栖息地保存位置。旧通用栖息地保留容量3和原有龙、金币；新建采用元素规则。

尚未还原：原版等距地块/碰撞/扩岛、升级期间产金细节、原版位图字体/部分界面细节、动作缓动/特效和未收集皮肤、装备/皇冠/羽翼/宝石、战斗和历史活动/抽奖。起始资源、旧通用栖息地仍为兼容测试配置，建筑信息/商店页面仍是临时排版。繁殖基础池不等于服务端实际概率。旧测试龙仅为存档兼容保留。

进化条件入口现可查看原版页面、15/25级门槛及对应品质的材料需求。当前只读预览，实际突破、果实库存和总战斗属性仍未实现；不能据此称进阶完成。“更多→原版龙谱→获取途径”可逐龙查看商店配置和全部正权重繁殖候选，抽奖/活动/冒险来源仍待核实。

## 基础抽奖
“更多→基础抽奖”可进行普通/高级单抽、十连。优先扣对应抽奖币，不足用魔晶补齐；待领取栏30格，资源手动领取，幼龙选择栖息地安置。满巢保留奖励，关闭/重启不重抽。

抽样采用明确标注的离线基础池解释：原表第7列作累计阈值，第5/6列作数量上下限；服务器概率/数量尚未核实，活动抽奖、免费/冷却、保底与票券获取尚未复刻。原转圈/特效、完整奖励卡仍待比对。

希望立即试玩可双击`抽奖试玩.cmd`，使用独立演示存档与测试资源；不会给正式牧场加币或改档。正式启动入口仍为`启动游戏.cmd`。

## 存档
桌面存档：`%APPDATA%/YulongRanch/saves/ranch-v1.json`，上一有效状态为 `.json.bak`。内部格式已升至v5并兼容迁移v1/v2/v3/v4，旧文件名保留以连续读取原存档。临时文件同步落盘后替换主文件。损坏时尝试备份，两个文件都不可读时阻止载入，避免覆盖。高版本存档阻止回退。

“存档”按钮支持保存与 JSON 导入/导出。导入会验证版本、资源、龙、容量、计时和编号。Ctrl+S 可手动保存。自动保存失败会保留界面中的旧状态并提示重试。

## 项目结构
- `src/game.mjs`：独立规则及存档校验，`src/data.mjs`：已接入原版数据与尚待替换的测试配置。
- `src/app.mjs` / `src/art.mjs` / `src/style.css`：界面；`src/original-hud.mjs`：原版布局 HUD。
- `desktop/`：Electron 安全隔离、本地存档与桌面验收。
- `tests/`：规则边界、离线计时、容量、损坏恢复、顺序写入验证。
- `docs/BASELINE.md`：初始检查；`docs/EVIDENCE.md`：来源；`docs/GAPS.md`：功能差异。
- `DEVELOPMENT.md`：续作记录与优先待办。

后期系统已记录范围，尚未实现的内容在差异清单和游戏“复刻进度”中明确说明。排除真人联机。
