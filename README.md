# 御龙高手

Windows PC 离线单机游戏开发项目。目标是依据可追溯资料复刻含后期内容的手机版《龙之牧场 / 育龙高手》。目前交付 **v0.4 元素栖息地接入版**，不是高保真完成版。

## 运行
- 双击 `启动游戏.cmd`，优先运行已打包 Windows 程序。
- 开发模式：Node.js 22.12+，`npm ci`，`node node_modules/electron/install.js`（首次下载桌面运行时），`npm start`。
- 可选浏览器预览：`npm run dev` → http://127.0.0.1:4173 。浏览器与桌面存档独立。
- `npm test` 检查规则与存档；`npm run package` 生成 `dist/御龙高手-v0.4.0-win32-x64/御龙高手.exe`（整个目录一起保留）。

## 当前玩法
1. 岛上点击农场，选择龙涎草（50 金币，30 秒，10 食物），或其他两种初级作物。农场可按原版等级、价格与时间升级，逐步开放 6 / 9 种作物。
2. “更多 → 我的龙族”喂养亲代；每级喂养 4 次，Lv4 可以繁殖。Lv4/Lv7 切换成长外观。
3. 繁殖巢选择两只不同龙。可预览客户端基础池；服务端加成尚未核对。本地结果在开始时确定并保存，时长使用对应后代的原版配置，可能是数小时。
4. 繁殖完成领取龙蛋、开始孵化、选择栖息地迎接幼龙。满时龙蛋保留，可以建造新栖息地。
5. 点击“收金币”收全部产出。“更多”访问存档、图鉴、养成和进度。关闭游戏后计时继续。

三种基础龙已接入三阶段原版呼吸动画，90 条龙种记录与原名已关联。其他龙目前使用原版图鉴缩略图；水晶/风/镜龙缺图明确留空。

栖息地现接入9种元素、18个原版定义：原版容量/存金上限、价格（含魔晶）、牧场等级门槛、建造/升级计时、完成经验、元素入住限制。17个在商店开放；41号大型传奇龙巢的客户端商店标志为关闭，不擅自开放。牧场里可拖动栖息地保存位置。旧通用栖息地保留容量3和原有龙、金币；新建采用元素规则。

尚未还原：原版等距地块/碰撞/扩岛、升级期间产金细节、独立并发繁殖孵化、完整动作/全部皮肤、装备/皇冠/羽翼/宝石、战斗和历史活动/抽奖。起始资源、旧通用栖息地仍为兼容测试配置，建筑信息/商店页面仍是临时排版。繁殖基础池不等于服务端实际概率。旧测试龙仅为存档兼容保留。

## 存档
桌面存档：`%APPDATA%/YulongRanch/saves/ranch-v1.json`，上一有效状态为 `.json.bak`。内部格式已升至v3并兼容迁移v1/v2，旧文件名保留以连续读取原存档。临时文件同步落盘后替换主文件。损坏时尝试备份，两个文件都不可读时阻止载入，避免覆盖。高版本存档阻止回退。

“存档”按钮支持保存与 JSON 导入/导出。导入会验证版本、资源、龙、容量、计时和编号。Ctrl+S 可手动保存。自动保存失败会保留界面中的旧状态并提示重试。

## 项目结构
- `src/game.mjs`：独立规则及存档校验，`src/data.mjs`：已接入原版数据与尚待替换的测试配置。
- `src/app.mjs` / `src/art.mjs` / `src/style.css`：界面；`src/original-hud.mjs`：原版布局 HUD。
- `desktop/`：Electron 安全隔离、本地存档与桌面验收。
- `tests/`：规则边界、离线计时、容量、损坏恢复、顺序写入验证。
- `docs/BASELINE.md`：初始检查；`docs/EVIDENCE.md`：来源；`docs/GAPS.md`：功能差异。
- `DEVELOPMENT.md`：续作记录与优先待办。

后期系统已记录范围，尚未实现的内容在差异清单和游戏“复刻进度”中明确说明。排除真人联机。
