# 素材登记

`original/` 已接入当乐 2.9.35 公开客户端的图集、物品/龙种配置和布局。来源、尺寸、转换方式与哈希见 original/manifest.json、data/provenance.json 和 docs/EVIDENCE.md 的 E04/E05。

三种基础龙已使用原版部件重构的三阶段呼吸动画；其他龙暂用原版图鉴缩略图。三个缺失龙图不以其他图冒充。旧版绯花/雾岚/流焰测试龙仅为存档兼容保留独立临时 SVG，当前原版龙繁殖不会生成它们。

原版截图证据放在 docs/reference，来源见 docs/EVIDENCE.md；不随游戏包发布为运行时素材。

原始 APK 和研究中间文件仅保存在忽略的 work/，不随运行包复制。研究结果按字段、图像/动作来源继续补齐；不是已完成全部皮肤与素材的声明。
