# 逐击血量战斗 — v0.16.61

删除旧battleTurnPlan的第三回合finishing逻辑。它原先让前期每击只显示掉10%血，最后直接以剩余血量作为伤害置零，导致玩家看到血量和伤害突然跳变。现在冒险、圣树、竞技和血战共享simulateCombat，结算和动画读取同一场战斗的生命值记录。

每只龙保有maxHp/currentHp；每击保存hpBefore、damage、appliedDamage、hpAfter。hpAfter=max(0,hpBefore-damage)，只有真正扣到0才阵亡，30回合仍有双方存活则结束为未胜，不强制杀死任何一方。头顶/场内血条和原伤害数字均读取这份记录。残血首领开场同时设置头像与场内血条，不能先伪装100%再跳到残局。

来源：玩家属性继续使用客户端成长、装备、宝石、培养、升星及被动技能数据。主动技能使用原damageVector（万分比）与damageValue（-1按无固定加值）；怪物优先读取其配置里的skill1/skill2，符文升级的系数/固定伤害参与实算，显示与伤害使用同一技能ID。

离线边界：防御减伤选用floor((attack*coefficient+flat)*max(1,attack)/(max(1,attack)+defend))、最低1点；奇数回合普通攻击、偶数回合特技、顺序目标规则是本地确定性规则。原服务器暴击概率、命中/闪避、怒气、持续伤害/控制/恢复、完整目标选择及跨波生命继承尚未恢复，不能称原服战斗AI已经一致。旧冒险模式的40%离线强度保留，但现在实际缩放敌人的攻/防/生命，而非只把判胜门槛设为40%并显示完整假血量。血战原怪物数值不套此缩放；圣树/竞技沿用既有自适应NPC数值。

验证：251规则测试覆盖同攻防同技能不随回合/剩余血增长、源技能系数/固定值、防御、正常过量击杀、逐击守恒、结算一致、满30回合仍存活；Windows源码及发布包回归6击，首/第三回合普通伤害均646，目标5000→4354→3314→2668未阵亡，两处血条与数字一致。残血首领5000上限从1000开始，受100伤害后900；血战实际鼠标增益/挑战/75丹结算/重置/150丹扫荡及19项活动回归通过。QA不操作正式存档。
