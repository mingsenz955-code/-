## 里程碑
- M0：空仓库版本基线、证据与差异清单（已建立）。
- M1：可运行牧场 → 龙粮 → 喂养 → 繁殖 → 孵化 → 栖息地 → 存档 → 重启恢复（本轮实施与验证）。
- M2：原版主界面和建筑/龙素材对照；多作物、建筑升级、自由摆放、真实龙种分批接入。
- M3：装备/皇冠/羽翼、宝石祭坛、升星与培养的数据及界面。
- M4：阵型、技能、单机副本与离线对手。
- M5：历史活动、抽奖、长期平衡、完整素材及逐屏高保真核验。

高保真完成标准：所有声明范围有来源、素材与数据可追溯；同状态截图对照；交互可操作；断网运行；存档迁移/恢复验证；不以菜单占位认定完工。
