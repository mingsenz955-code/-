本轮依据本地 Android 客户端 2.9.35-202402271124 恢复 **76个独立活动版本、1434行原配置奖励**。这不是“所有原版历史活动已完美复刻”的结论；同名历史版本分别保存奖池与进度，所有入口常驻开放是用户要求的离线适配。

- 首充、新手礼包、成长计划、每月/十五日签到、七日福利和五日/七日充值：按条件领取、购买、库存发放、重复领取保护。
- 消费返利、充值返利、四期土豪节、双十一消费红包、单笔充值：独立领取记录；按实际消费累计，不把返还奖励抵扣消费。双十一分别记录前四日消费，四日后返10%。
- 宝石/强化材料特惠、橙装抢购、充值限购、积分/碎片兑换、七夕玫瑰、宝箱回馈、神龙收集和紫装送礼：实际扣除费用或材料，奖励进入对应库存。

- 月卡/福袋使用本地测试购买和每日领取；新春红包只拆自己的本地存款；不调用真实支付或发送给他人。

## 来源与可复现性

`scripts/export-activities.py` 从已导出的原表和本地APK导出活动，使用静态Lua表读取器，不执行原客户端Lua。`docs/reference/activities-source.json` 记录表哈希、每个活动的来源表、费用和离线解释。

关键列由 `LibraryManager` 的表—Info类映射、Info构造函数和活动UI调用链核对：`NewyearTaskInfo/NewyearCostInfo`、`LibTrainScoreInfo`、`EggRewardInfo`、`ErTongInfo` 等。大富翁保留三张原49点路线；培养保留 `Dragon_peiyang` 的费用、成功率与阶段上限。页面使用原图片、品质框、龙骨骼与部分原布局组合，尚未逐屏验证所有活动的原运行时布局。

| 春节HARD任务 | 原驯龙挑战HARD玩法未接通；该任务保留原要求并禁领，未拿其它战斗替代；圣树胜利任务仍受当前每日NPC数量限制，尚缺原刷新机制。 |
| 点燃圣火资格 | 原UI涉及圣火/祭品/水晶事件与服务器返回次数；精确资格缺失，当前30魔晶为明确的本地抽取设置。 |
| 在线兑换码/邀请/外部平台礼包 | 原兑换码数据库、真实邀请验证、平台领取资格均缺失。不伪造线上有效码或好友。 |
| 一元礼包/一元十倍返利 | 客户端入口存在，部分实际礼包内容/资格由服务器下发；未用任意奖励填充。 |

| 数值/概率 | 随机奖池权重解释、培养增量/完美率与积分、部分购买资格/月卡期限、大富翁每骰消耗和补票均在活动说明标出离线规则。 |
| 旧版材料用途 | 无可验证消费者的旧版符文碎片等保存在活动背包，不能冒充已可装备的现代符文。 |

## v0.16.42 核查修正

充值日奖励曾误用登录天数，五日最终奖励漏校验累计充值条件。现以充值达标日计数，并按HD68Part原UI的5日、200元双条件检查最终奖；来源表保留原2000值，金额展示按原UI200元核对。旧奖励不追扣或回滚。其余活动仍有上文缺口，测试通过仅代表已覆盖的实现行为，不证明与原服务器一致。
